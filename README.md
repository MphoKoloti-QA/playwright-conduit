# Playwright Automation Framework

Automation framework built using Playwright + TypeScript.

## Tech Stack
- Playwright
- TypeScript
- Node.js
- GitHub

## Features
- UI Automation
- API Testing
- Page Object Model
- Cross-browser testing
- Reporting
- CI/CD Ready

## Project Structure

```bash
tests/
pages/
utils/
fixtures/
```

## Installation

```bash
npm install
```

## Run Tests

```bash
npx playwright test
```

## Run Specific Test

```bash
npx playwright test login.spec.ts
```

## Generate Report

```bash
npx playwright show-report
```
